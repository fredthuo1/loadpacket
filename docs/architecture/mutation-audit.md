# Mutation and transaction audit

Status: source review 2026-10-01. No endpoint was invoked. [Route inventory](mutation-route-inventory.md) lists controller mutation declarations and source lines; module wiring must be respected, including unregistered draft files. All families must adopt durable operation semantics rather than infer idempotency from HTTP verb or a state check.

Important exception: read-like broker access may update lastAccessedAt; READ_ONLY design must inventory hidden writes rather than allow every GET. Downloads/grant issue must reauthorize and never persist sensitive grant tokens in generic idempotency responses. For provider actions use staged intent so “invited/submitted” accurately describes what is confirmed.

Current transactions are PostgreSQL-specific (`FOR UPDATE`, advisory locks and triggers). New distributed retry loops must not repeat file puts, email, purchases or audit outside the transaction. Commit uncertainty cleanup already preserves artifacts in several services; retain this safety. See [shared protocol](data-durability.md) and LP-PROD-006/007/023.
